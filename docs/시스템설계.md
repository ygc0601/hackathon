# 시스템 설계

## 구성요소

| 구성요소 | 책임 |
|---|---|
| 당사자 앱 | 쉬운 말 표시, TTS, 미션 수행, 사진 인증, SOS, 승인 대기 |
| 보호자 앱 | 접근성 설정, 미션 편집, 승인 처리, 활동 리포트 |
| 백엔드 API | 인증, 권한 검사, 데이터 저장, 상태 동기화 |
| AI 처리 서비스 | OCR, 쉬운 말 변환, 픽토그램 후보 매칭 |
| 알림 서비스 | 미션·SOS·승인 요청 알림 전달 |
| 파일 저장소 | 암호화된 사진과 음성 저장 |

## 로그인 및 기기 연결

```text
[보호자 이메일 로그인] → [10분 연결 코드 생성]
                              ↓
[당사자 익명 기기 인증] → [코드 1회 사용] → [보호자 설정 읽기]
```

- 보호자는 Firebase 이메일 계정으로 로그인한다.
- 당사자 기기는 이메일 없이 Firebase 익명 인증으로 기기별 UID를 발급받는다.
- 연결 코드는 모호한 문자를 제외한 8자리이며 10분 후 만료되고 한 번만 사용할 수 있다.
- 보호자는 접근성 설정을 읽고 수정할 수 있으며 연결된 당사자 기기는 읽기만 가능하다.
- 화면 주소가 아니라 Firestore Security Rules에서 역할과 연결 관계를 검사한다.

### 로그인 데이터

| 컬렉션 | 용도 |
|---|---|
| `userProfiles/{guardianUid}` | 보호자 계정 프로필 |
| `accessibilityProfiles/{guardianUid}` | 보호자가 관리하는 읽기 환경 설정 |
| `pairingCodes/{code}` | 만료 시간과 사용 상태를 가진 일회용 연결 코드 |
| `deviceLinks/{deviceUid}` | 당사자 기기 UID와 보호자 UID의 연결 관계 |

## 논리 구조

```text
[보호자 앱] ─┐
              ├─ [인증·권한 API] ─ [프로필/미션/활동 DB]
[당사자 앱] ─┘          │
       │                 ├─ [알림 서비스]
       └─ 문서 촬영 ─ [OCR] ─ [쉬운 말 변환] ─ [검증/주의 표시]
```

## 주요 데이터

- `User`: 사용자 ID, 역할, 보호자 연결 관계
- `AccessibilityProfile`: 글 난이도, 글자 크기, 픽토그램, TTS 속도
- `Mission`: 제목, 예약 시간, 상태, 단계 목록
- `MissionStep`: 순서, 쉬운 지시문, 사진, 음성
- `ActivityLog`: 시작·완료 시간, 도움 요청, 인증 사진
- `ApprovalRequest`: 모의 거래 정보, 요청 시각, 상태, 보호자 응답

## 안전 상태 전이

모의 금융 요청은 `대기`에서 시작하고 `승인`, `차단`, `시간 초과` 중 하나로 종료한다. 통신 오류, 보호자 미응답, AI 분석 실패는 모두 `승인`이 아닌 `시간 초과/차단`으로 처리한다.

## 쉬운 말 검증

- 원문과 변환문에서 날짜, 시간, 장소, 금액, 연락처, 해야 할 행동을 구조화해 비교한다.
- 누락 또는 불일치가 발견되면 경고 표시와 보호자 확인 버튼을 제공한다.
- 변환 결과를 금융·의료·법률 판단으로 표현하지 않는다.
- 원본 이미지와 추출 텍스트를 함께 확인할 수 있도록 한다.

## MVP 구현 원칙

해커톤 시연에서는 OS 수준의 은행 앱 탐지나 잠금 기능을 주장하지 않는다. 별도의 모의 금융 화면에서 승인 흐름과 실패 안전 원칙을 구현하고, 실제 제품화에는 운영체제 및 금융기관 연동 검토가 필요함을 명시한다.
