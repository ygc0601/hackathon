# 개인정보 및 안전 원칙

## 최소 수집

- 서비스에 필요한 계정, 접근성 설정, 미션 및 수행 기록만 수집한다.
- 계좌 비밀번호, 보안카드, 인증번호를 저장하거나 요구하지 않는다.
- 위치 정보는 MVP에서 수집하지 않는다.

## 동의와 통제

- 당사자가 이해할 수 있는 쉬운 말로 수집 목적과 삭제 방법을 설명한다.
- 법정대리인 동의가 필요해도 가능한 범위에서 당사자의 의사와 거부를 존중한다.
- 사진·음성·활동 기록별 보관 기간과 공유 대상을 설정할 수 있게 한다.

## 접근 권한과 보관

- 당사자와 연결된 보호자만 기록에 접근한다.
- 역할 기반 권한 검사와 보호자 계정의 추가 인증을 적용한다.
- 통신 구간과 저장된 사진·음성을 암호화한다.
- 공개 저장소에 실제 사용자 데이터, API 키, 인증 정보를 올리지 않는다.
- 테스트 자료에는 익명 코드를 사용하고 목적 달성 후 삭제한다.

## AI 및 금융 안전

- AI 출력의 오류 가능성을 알리고 중요 정보는 원문과 함께 제시한다.
- AI는 송금의 최종 승인자가 되지 않는다.
- 보호자 미응답, 서버 장애, 신뢰도 부족 시 기본 상태는 대기 또는 차단이다.
- MVP 금융 기능은 모의 흐름이며 실제 은행 앱을 제어한다고 표현하지 않는다.

## 긴급 상황

앱은 긴급 구조 서비스를 대체하지 않는다. SOS 실패 시 사용할 보호자 전화 등 대체 연락 수단을 쉬운 화면으로 제공한다.
