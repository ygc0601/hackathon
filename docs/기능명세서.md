# 기능명세서

## 사용자 역할

- **당사자:** 쉬운 말 확인, 미션 수행, 사진 인증, 도움 요청
- **보호자:** 접근성 설정, 미션 관리, 승인 요청 처리, 활동 확인
- **운영자(향후):** 계정·신고·장애 대응. MVP에서는 제외

## MVP 기능

| ID | 기능 | 사용자 | 우선순위 | 완료 조건 |
|---|---|---|---|---|
| P-01 | 접근성 프로필 설정 | 보호자 | 필수 | 글 난이도·픽토그램·글자 크기·음성 속도 저장 및 반영 |
| P-02 | 단계별 미션 생성 | 보호자 | 필수 | 단계마다 문장·사진·음성을 등록하고 예약 가능 |
| U-01 | 단순 홈 화면 | 당사자 | 필수 | 쉬운 말과 오늘의 미션 버튼만 주요 영역에 표시 |
| U-02 | 문서 촬영·쉬운 말 | 당사자 | 필수 | 촬영→OCR→변환→큰 글자 출력 흐름 작동 |
| U-03 | 픽토그램·TTS | 당사자 | 필수 | 설정에 따라 그림과 느린 음성, 읽기 강조 제공 |
| U-04 | 단계별 미션 수행 | 당사자 | 필수 | 한 화면에 한 단계, 사진 인증 후 다음 단계 이동 |
| U-05 | SOS 도움 요청 | 당사자 | 필수 | 모든 미션 화면에서 보호자에게 알림 전송 |
| S-01 | 금융 승인 시연 | 양쪽 | 필수 | 모의 거래에서 대기→승인/차단 결과 표시 |
| R-01 | 활동 리포트 | 보호자 | 권장 | 완료율·소요 시간·도움 요청을 시각화 |

## 핵심 사용자 흐름

### 쉬운 말

홈 → 카메라 → 문서 촬영 → 글자 인식 → 쉬운 말 변환 → 핵심정보 확인 표시 → 큰 글자·그림·음성 재생

### 미션

알림 또는 홈 → 미션 시작 → 현재 한 단계 확인 → 행동 수행 → 사진 인증 → 성공 안내 → 다음 단계 → 완료

### 금융 안전 시연

모의 금융 화면 진입 → 보호자 확인 대기 → 보호자에게 거래 정보 알림 → 승인 또는 차단 → 당사자 화면에 결과 표시

## 비기능 요구사항

- 주요 터치 영역은 충분히 크게 제공하고 서로 가깝게 배치하지 않는다.
- 쉬운 문장은 한 문장에 한 행동을 담는다.
- 오류 메시지는 원인과 다음 행동을 쉬운 말로 안내한다.
- AI 응답 실패 시 원문을 임의로 해석하지 않고 보호자 확인을 요청한다.
- 사진·음성·활동 기록은 사용자별 권한과 보관 정책을 적용한다.
- 금융 승인 요청은 기본값을 대기 또는 차단으로 두며 자동 승인하지 않는다.

## MVP 제외 범위

- 실제 은행 앱 강제 잠금 및 실제 송금 승인
- 의료 진단 또는 복약 처방 판단
- AI에 의한 금융 사기 최종 판정
- 실시간 위치 추적
