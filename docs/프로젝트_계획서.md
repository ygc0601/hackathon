# 한걸음 프로젝트 계획서

## 1. 프로젝트 개요

본 프로젝트의 작품명은 가칭 ‘같이 읽기’이다. 한걸음은 지적·발달장애인이 우편물, 공공기관 안내문, 복약 안내문과 같은 생활 문서를 쉽게 이해할 수 있도록 지원하는 개인 맞춤형 쉬운 말 번역 웹 서비스이다.

사용자가 문서를 촬영하면 시스템이 문서의 글자를 인식하고, 보호자가 설정한 사용자의 인지 수준에 맞추어 내용을 쉬운 문장으로 변환한다. 변환된 내용은 큰 글자와 느린 음성으로 제공하며 날짜, 장소, 금액, 준비물, 해야 할 행동과 같은 핵심정보를 별도로 표시한다.

본 프로젝트는 단순한 문장 요약 서비스가 아니라 사용자의 인지 특성과 선호하는 의사소통 방식을 반영하는 접근성 중심의 번역 서비스를 목표로 한다.

## 2. 추진 배경

지적·발달장애인은 개인에 따라 문해력, 인지 능력, 정보 처리 속도, 선호하는 의사소통 방식에서 큰 차이를 보인다. 그러나 공공기관 안내문, 금융 문서, 복약 안내문 등 일상에서 접하는 문서는 대부분 복잡한 용어와 긴 문장으로 작성되어 있다.

이로 인해 당사자는 글자를 읽을 수 있더라도 문서의 의미를 정확히 이해하거나 자신이 해야 할 행동을 판단하기 어려울 수 있다. 특히 날짜, 금액, 장소와 같은 중요정보를 잘못 이해하면 행정 처리 누락, 복약 오류, 금융 피해 등으로 이어질 가능성이 있다.

기존 쉬운 글 변환 서비스는 일반적인 문장 단순화에 집중하고 있으며, 사용자별 인지 수준과 문장 길이, 글자 크기, 음성 속도를 종합적으로 반영하는 기능은 제한적이다. 또한 생성형 인공지능은 번역 과정에서 원문 정보를 누락하거나 존재하지 않는 내용을 추가할 가능성이 있으므로 중요정보를 별도로 검증하는 안전장치가 필요하다.

## 3. 프로젝트 목표

본 프로젝트의 최종 목표는 지적·발달장애인이 타인의 지속적인 설명 없이 생활 문서의 핵심 내용을 이해할 수 있도록 지원하는 것이다.

이를 위해 문서 촬영만으로 쉬운 말 번역을 실행할 수 있는 단순한 사용자 인터페이스를 구현한다. 사용자의 인지 수준에 따라 문장 길이, 단어 난이도, 글자 크기와 음성 속도를 조정한다. 번역 결과에서 날짜, 시간, 장소, 금액, 연락처, 준비물과 해야 할 행동을 별도로 추출하여 제공한다. 원문과 번역문의 중요정보를 비교하여 누락이나 변경 가능성을 표시하고, 결과가 불확실하거나 고위험 문서로 판단되는 경우 보호자에게 확인을 요청할 수 있도록 한다.

## 4. 주요 사용자

서비스의 주요 사용자는 당사자와 보호자로 구분한다.

당사자는 지적·발달장애인으로서 문서를 촬영하고 쉬운 말 번역 결과를 확인한다. 당사자 화면은 인지적 부담을 줄이기 위해 필요한 기능만 표시하며, 한 화면에 하나의 핵심 문장을 제공한다.

보호자는 당사자의 접근성 설정을 관리하고 필요한 경우 번역 결과를 검토한다. 보호자는 원본 문서, OCR로 추출된 문장, 쉬운 말 번역 결과와 핵심정보를 비교하고 잘못된 내용을 수정할 수 있다.

## 5. 주요 기능

당사자용 초기 화면에는 ‘카메라로 쉬운 말 보기’ 버튼을 크게 표시한다. 사용자는 해당 버튼을 눌러 문서를 촬영하거나 저장된 이미지를 선택할 수 있다.

촬영된 문서는 OCR 기술을 통해 텍스트로 변환한다. 추출된 텍스트는 사용자의 접근성 프로필에 따라 쉬운 단어와 짧은 문장으로 변경한다. 하나의 문장에는 하나의 정보 또는 행동만 포함하도록 구성한다.

번역 결과는 쉬운 글과 음성으로 제공한다. 음성 안내가 재생되는 동안 현재 읽고 있는 문장이나 단어를 강조하여 사용자가 내용을 따라갈 수 있도록 한다.

날짜, 시간, 장소, 금액, 연락처, 준비물과 해야 할 행동은 본문과 분리된 정보 카드로 제공한다. 이를 통해 사용자가 문서 전체를 다시 읽지 않아도 중요한 내용을 확인할 수 있도록 한다.

보호자 화면에서는 사용자의 쉬운 말 난이도, 문장 길이, 글자 크기, 음성 속도와 고대비 화면을 설정한다. 설정 결과는 당사자 화면에 자동으로 반영한다.

번역 결과가 불확실하거나 금융, 의료, 법률과 관련된 중요 문서인 경우 보호자 확인 요청 기능을 제공한다. 보호자는 원문과 번역문을 비교한 후 내용을 수정하거나 확인할 수 있다.

## 6. 작동 원리

사용자가 문서를 촬영하면 시스템은 이미지 품질을 확인하고 OCR을 통해 원문을 추출한다. 이후 원문에서 날짜, 시간, 장소, 금액, 전화번호, 준비물과 행동 정보를 구조화하여 분리한다.

추출된 원문은 사용자의 접근성 프로필과 함께 쉬운 말 변환 시스템으로 전달한다. 변환 시스템은 문장을 짧게 나누고 어려운 단어를 쉬운 표현으로 변경한다. 사용자가 해야 할 행동이 포함된 경우 해당 행동을 명확한 문장으로 표시한다.

변환이 완료되면 시스템은 원문과 번역문에서 추출된 핵심정보를 비교한다. 중요정보가 누락되거나 변경된 경우 번역 결과를 확정하지 않고 경고를 표시한다. 신뢰도가 낮거나 위험 가능성이 있는 문서는 보호자 확인 대상으로 분류한다.

검증된 결과는 사용자의 설정에 따라 큰 글자와 느린 음성으로 제공한다.

## 7. MVP 범위

MVP에서는 문서 촬영, 이미지 선택, OCR, 개인 맞춤형 쉬운 말 변환, 핵심정보 추출, 큰 글자 표시, TTS 음성 안내, 읽기 강조, 접근성 프로필 설정과 보호자 확인 요청 기능을 구현한다.

미션 생성, 미션 예약, 단계별 행동 수행, 사진 인증, 미션 완료 통계와 활동 리포트 기능은 MVP에서 제외한다.

실제 은행 앱 탐지, 다른 앱 잠금, 실제 송금 승인, 의료적 판단, 금융 사기 확정 판정과 실시간 위치 추적 기능도 MVP에서 제외한다. 금융 관련 기능은 문서에서 송금 요구, 계좌번호, 인증번호 요구와 같은 위험 가능성을 발견했을 때 보호자 확인을 요청하는 범위로 제한한다.

## 8. 기술 구성

프런트엔드는 React와 TypeScript를 사용하며 개발 환경은 Vite로 구성한다. 하나의 React 프로젝트 안에서 당사자 화면과 보호자 화면을 역할별 경로로 구분한다.

백엔드는 사용자 인증, 접근성 설정, 번역 기록과 보호자 연결 정보를 관리한다. 초기 구현에서는 빠른 개발을 위해 Supabase를 사용하는 방안을 적용한다. 사진과 번역 결과는 사용자별 접근 권한을 설정하여 보호한다.

OCR과 쉬운 말 변환 기능은 각각 독립된 서비스로 분리한다. 이를 통해 해커톤 시연용 데이터와 실제 외부 API를 쉽게 교체할 수 있도록 구성한다.

브라우저 카메라 기능을 사용하기 위해 서비스는 HTTPS 환경에 배포한다. 음성 안내는 브라우저의 한국어 TTS 기능을 우선 사용한다.

## 9. 개인정보 및 안전 원칙

서비스는 기능 제공에 필요한 최소한의 개인정보만 수집한다. 촬영한 문서에는 이름, 주소, 계좌정보 등 민감한 정보가 포함될 수 있으므로 저장 여부와 삭제 기능을 명확하게 제공한다.

계좌 비밀번호, 보안카드 번호와 인증번호는 저장하거나 입력하도록 요구하지 않는다. 실제 사용자 데이터와 API 인증정보는 공개 GitHub 저장소에 등록하지 않는다.

AI가 생성한 번역문은 확정된 사실로 간주하지 않는다. 원본 문서와 OCR 결과를 함께 확인할 수 있도록 하며 날짜, 금액, 장소와 같은 중요정보가 일치하지 않을 경우 사용자에게 결과를 제공하기 전에 경고한다.

의료, 금융, 법률 문서는 자동 판단 대상이 아니라 보호자 또는 전문가의 확인이 필요한 문서로 처리한다.

## 10. 제작 일정

첫 번째 단계에서는 프로젝트 구조를 구성하고 당사자와 보호자 화면의 기본 디자인을 제작한다. 이 단계에서 공통 색상, 글자 크기, 버튼 크기와 접근성 설정 기준을 확정한다.

두 번째 단계에서는 카메라 촬영과 이미지 선택 기능을 구현하고 OCR 결과를 화면에 표시한다.

세 번째 단계에서는 쉬운 말 변환과 핵심정보 추출 기능을 연결한다. 초기에는 준비된 예제 문서를 활용하여 안정적인 시연 흐름을 완성하고 이후 실제 API를 연결한다.

네 번째 단계에서는 TTS, 읽기 강조와 접근성 프로필 기능을 구현한다.

다섯 번째 단계에서는 보호자 확인 요청과 번역 결과 수정 기능을 구현한다.

마지막 단계에서는 모바일 환경, 카메라 권한, 음성 재생, AI 오류, 네트워크 장애와 개인정보 처리 기능을 테스트하고 발표용 시연을 준비한다.

## 11. 테스트 계획

테스트의 목적은 사용자가 번역 결과를 통해 문서의 핵심 내용을 정확하게 이해할 수 있는지 확인하는 것이다.

공공기관 안내문, 복약 안내문, 금융 관련 안내문 등 여러 유형의 예제 문서를 준비한다. 각 문서에는 날짜, 장소, 금액과 행동 정보를 포함한다. OCR 결과와 원문을 비교하고 쉬운 말 번역 전후에 핵심정보가 유지되는지 확인한다.

사용성 테스트에서는 사용자가 문서의 목적, 해야 할 행동, 기한과 장소를 정확하게 답할 수 있는지 측정한다. 또한 주요 버튼의 오조작 횟수, 결과 확인 시간과 보호자 도움 요청 여부를 기록한다.

AI 또는 네트워크 오류가 발생했을 때 잘못된 번역을 정상 결과로 표시하지 않는지도 확인한다. 고위험 문서는 보호자 확인 전까지 확정된 행동을 안내하지 않아야 한다.

## 12. 예상 성과

준비된 문서에 대한 OCR 핵심정보 인식률은 95퍼센트 이상을 목표로 한다. 쉬운 말 번역 후 날짜, 장소, 금액과 행동 정보의 보존율도 95퍼센트 이상을 목표로 한다.

사용자가 번역 결과를 확인한 후 문서의 핵심 내용을 올바르게 답하는 비율은 80퍼센트 이상을 목표로 한다. 원문에 없는 중요 행동을 AI가 추가하는 경우와 고위험 문서를 보호자 확인 없이 확정하는 경우는 모두 0건을 목표로 한다.

## 13. 기대 효과

당사자는 우편물이나 안내문을 받았을 때 주변 사람에게 매번 설명을 요청하지 않고 문서의 핵심 내용을 확인할 수 있다. 이를 통해 정보 접근성과 일상생활의 자립성을 높일 수 있다.

보호자는 당사자의 이해 수준에 맞는 안내 방식을 미리 설정하고 중요한 문서에 대해서만 확인할 수 있다. 이를 통해 반복적인 설명 부담을 줄이는 동시에 위험한 오해를 예방할 수 있다.

본 프로젝트는 기존 쉬운 글 서비스와 달리 개인별 접근성 설정, 음성 안내, 핵심정보 검증과 보호자 확인을 하나의 번역 과정으로 통합한다는 점에서 차별성을 갖는다.
