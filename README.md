# 해커톤 프로젝트

지적·발달장애인의 일상 자립과 금융 안전을 돕는 보호자 연계형 접근성 앱 프로젝트입니다.

## 핵심 목표

- 어려운 문서를 개인 인지 수준에 맞는 쉬운 말·픽토그램·느린 음성으로 안내
- 일상 과제를 한 단계씩 수행하고 사진으로 인증
- 보호자 설정, 도움 요청, 활동 리포트를 통한 원격 돌봄 지원
- 금융 앱 이용 시 보호자 확인을 요청하는 안전 흐름 제공

## 문서

- `PROJECT_RULES.md`: 작업 규칙
- `docs/해커톤_보고서.md`: 해커톤 보고서 본문
- `docs/기능명세서.md`: 사용자별 기능과 MVP 범위
- `docs/시스템설계.md`: 소프트웨어 구조 및 작동 원리
- `docs/테스트계획.md`: 테스트 지표와 기록 양식
- `docs/개인정보_안전원칙.md`: 개인정보·금융 안전 원칙

## 협업 규칙

- 기본 브랜치는 `main`을 사용합니다.
- 기능 작업은 별도 브랜치에서 진행합니다.
- 커밋에는 한 가지 목적의 변경만 포함합니다.
- 실제 이용자 대상 테스트는 사전 동의와 보호자·전문가 감독하에 진행합니다.
