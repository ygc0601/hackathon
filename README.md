# 해커톤 프로젝트

지적·발달장애인이 어려운 문서를 쉬운말·픽토그램·음성으로 이해하도록 돕는 보호자 연계형 접근성 앱 프로젝트입니다.

## 핵심 목표

- 어려운 문서를 개인 인지 수준에 맞는 쉬운 말·픽토그램·느린 음성으로 안내
- 보호자 계정과 당사자 기기를 일회용 코드로 안전하게 연결
- 보호자는 읽기 환경을 수정하고 당사자 기기는 설정을 읽기만 하도록 권한 분리
- OCR 원문과 중요 정보를 보존한 쉬운말 변환 제공

## 로그인 테스트

1. 일반 브라우저 창에서 보호자 계정으로 로그인합니다.
2. 보호자 화면에서 10분짜리 연결 코드를 만듭니다.
3. 시크릿 창에서 `당사자 기기`를 선택하고 코드를 입력합니다.
4. 보호자 설정 변경이 당사자 화면에 반영되는지 확인합니다.
5. 보호자 화면에서 기기 연결을 해제하고 당사자 접근이 종료되는지 확인합니다.

## 협업 규칙

- 기본 브랜치는 `main`을 사용합니다.
- 기능 작업은 별도 브랜치에서 진행합니다.
- 커밋에는 한 가지 목적의 변경만 포함합니다.
- 실제 이용자 대상 테스트는 사전 동의와 보호자·전문가 감독하에 진행합니다.
